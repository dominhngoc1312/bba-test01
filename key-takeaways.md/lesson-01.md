Cài đặt Playwright: 
- Tạo thư mục: demo-1
- Mở thư mục bằng VS Code
- Mở termino
- Chạy lệnh: npm init playwright@latest
- Gõ enter liên tục

========================

Đưa code lên GitHub:
- Khởi tạo repo local: git init 
- Tạo repo Github và liên kết tới repo local: git remote add origin <url>
- Thêm file vào staging: git add .
- Commit file lên vùng working: git commit -m"message"
- Push code lên Github: git push origin main
